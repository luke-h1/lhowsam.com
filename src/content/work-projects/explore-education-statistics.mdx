During my time at Hive IT I worked on one of the company's flagship projects, EES (explore education statistics). This service was a replacement for the DFE's (department for education) inefficient way of delivering statistics to the public. Previously statisticians published very long PDF + word documents which simply didn't appeal to the target audience / was very hard to read through.

The solution was to build a data platform Utilising modern technologies such as Next.js, C# + Dotnet, Azure to create a scalable platform in which statisticians could turn CSV documents into things such as charts, tables free-form text content etc.

During my time on this project I held three different roles.

- Junior software tester - Took over responsibilities from the previous tester
- Software tester - Started to heavily contribute to automation tests, improvements to test pipelines etc.
- Software engineer - transitioned to be a full-stack developer on the project working on things like DevOps improvements, feature + maintenance tasks etc.
