Worked on a full stack Next.js project where we were tasked with creating a point of service for young people struggling with their mental health. The site is designed to prompt users to figure out what emotions they are feeling and then based on that, we try to recommend certain actions which can help. After going through a workshop/user research phase, we started to build the project using [sanity.io](https://www.sanity.io/) and [Next.js](https://nextjs.org/). While the project did have a tight deadline (2 1/2 months) it was super fun and rewarding to work on this project.

Tech stack:

- Next.js - Frontend
- Sanity.io - Headless CMS / backend
- Vercel - Hosting
- Gitlab - CI/CD + code repository
