## Overview

Notes and resources from a meetup talk on shipping safely with feature flags, experimenting in production, and keeping rollback paths short.

## Takeaways

- Feature flags decouple deployment from release.
- Start with a small set of well-named flags and clean them up aggressively.
- Pair flags with observability so you can see impact quickly.
