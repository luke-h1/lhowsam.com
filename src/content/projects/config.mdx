I am a huge advocate for automation as this allows developers to focus on innovating new features and solving new problems rather than being backlogged with maintaining existing infrastructure. This project houses various configuration scripts to setup development environments (such as when you're setting up a new laptop) and much more.
This repository saves me lots of time when it comes to setting up new projects or setting up a new laptop.
